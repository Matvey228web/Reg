# site — публичный сайт проката

Витрина для студентов и сторонних: что есть на складе, свободно ли это на
выбранные даты, и как это попросить. [mifs-site.pages.dev](https://mifs-site.pages.dev)

Отдельный проект Pages, а не страница внутри склада: у сайта свой адрес, свои
правила кэша и своя выкладка, и перевезти его на другой хостинг можно, не
трогая склад.

## Два уровня данных

Публичная страница не может ждать 5–8 секунд, поэтому каталог и наличие
разведены.

**`catalog.json`** — снимок: категории, модели, сколько единиц всего. Лежит
статикой рядом со страницей, открывается мгновенно и работает, даже когда
бэкенд недоступен. Пересобирается перед выкладкой:

```sh
node site/build-catalog.js          # пишет site/catalog.json
node site/build-catalog.js --print  # показать, ничего не записывая
```

**Наличие на даты** — один живой запрос к `/public/catalog`, и только когда
человек выбрал даты. Оно меняется каждый час, снимком его брать нельзя.

Не удалось спросить — каталог остаётся на экране, а количества честно
объявляются неизвестными. Показать вчерашние числа хуже: по ним человек поедет
за техникой.

## Страницы

| Файл | Что показывает |
|---|---|
| `index.html` · `app.js` | витрина: группы по категориям, поиск, фильтр, даты |
| `item.html` · `item.js` | страница позиции и кнопка «В заявку» |
| `cart.html` · `cart.js` | состав заявки, данные студента, текст для склада |
| `common.js` | снимок, корзина в браузере, счётчик в шапке |

## Заявка уходит текстом

Входа на сайте пока нет, и открытая запись в таблицу без него — дверь для
чужих. Поэтому корзина **не пишет в базу**, а собирает текст ровно того вида,
который бэкенд разбирает с первого дня (`parseOrderMessage` в
`apps-script/Code.gs`): строка «Заказ №…», позиции «N. Название: 0 (кол-во x 0)»
и пары «Ключ: значение».

Студент копирует и отправляет складу любым способом, складмен вставляет в
«Заказы» — разбор и подтверждение там уже работают. **От Telegram это не
зависит.**

Слово «Заказ» в первой строке обязательно: его ищет разбор. На самом сайте мы
говорим «заявка», но строка едет складу и должна быть на его языке.

## Фотографии

Кладутся файлами: `photos/<КАТЕГОРИЯ>-<код>.jpg`, например `photos/CAM-01.jpg`.
Ни базы, ни бэкенда — добавить снимок значит положить файл и выложить сайт.
Фотографии нет — карточка показывает нейтральный знак.

К единому виду приводит `photos.py`: квадрат 800×800, фон карточки, предмет по
центру с одинаковым полем, однотонные поля исходника обрезаются.

```sh
python3 site/photos.py источники/        # папку целиком
python3 site/photos.py CAM-01.png        # один файл
```

Имя исходника — это ключ позиции, он же виден в карточке на сайте.

**Источник снимков — открытый вопрос.** Картинки с сайтов производителей
скачиваются и обрабатываются, но выбрать нужную автоматически нельзя: по
первой ссылке обычно лежит рекламный баннер с тремя изделиями и текстом, а не
фото товара. Плюс они чужие. Свои снимки на одном фоне и законны, и показывают
настоящее состояние техники.

## Оформление

Тёмная тема всегда, прямые углы, плотная решётка, красный только на действии —
взято у kino.rent. Со складским приложением общего языка форм нет намеренно:
витрина проката не должна читаться как служебная программа.

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0d0d0f` | фон страницы |
| `--panel` | `#141417` | карточки и блоки |
| `--line` | `#26262b` | границы и решётка |
| `--ink` | `#f2f2f3` | текст |
| `--dim` | `#8a8a93` | подписи |
| `--accent` | `#e2231a` | заливка кнопок |
| `--accent-text` | `#ff4b3e` | тот же смысл текстом |

Красных два не по недосмотру: `#e2231a` на тёмном даёт 4.15 — этого хватает
крупной кнопке, но мало мелкой строке. У `#ff4b3e` контраст 5.85.

Линии решётки рисует контур карточки (`box-shadow`), а не заливка сетки: иначе
в неполном ряду пустые ячейки превращаются в серые пятна и читаются как
сломанные карточки.

Веб-шрифты не подключаем — это ещё одна чужая зависимость, а мы от них уходим.

## Правила, которых стоит держаться

**Никакого Telegram.** Ни SDK, ни ссылок, ни зависимости от бота. Сайт должен
открываться, когда мессенджер недоступен.

**Ничего, специфичного для Cloudflare.** Обычная статика: переезд на другой
хостинг — копия файлов и запись DNS. Cloudflare в России ограничивают, и это
не гипотеза.

**Вес.** Три страницы со снимком каталога — 64 КБ. Ориентир «работает на слабом
телефоне» держим: без фреймворков, картинки ленивые и с заданными размерами.

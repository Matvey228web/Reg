# Mifs Rent

Учёт и прокат съёмочного оборудования Киноколледжа № 40 «Московская
международная киношкола». Четыре части, каждая живёт и выкладывается отдельно.

| Папка | Что это | Где работает |
|---|---|---|
| [`app/`](app/) | Склад: каталог, выдача и приём по QR, дефекты, сверка, этикетки | [mifs-rent.pages.dev](https://mifs-rent.pages.dev) |
| [`site/`](site/) | Публичный сайт проката: витрина и заявка | [mifs-site.pages.dev](https://mifs-site.pages.dev) |
| [`apps-script/`](apps-script/) | Бэкенд: вся логика одним файлом, данные в Google Sheets | Google Apps Script |
| [`worker/`](worker/) | Кэш перед таблицей. Написан, **не включён** | Cloudflare Worker |

## Как это устроено целиком

```
 студент                     сотрудник склада
    │                              │
 site/  ── заявка текстом ──▶  app/  ──▶  apps-script/  ──▶  Google Sheets
    │                              │            ▲
    └── витрина ── catalog.json ───┘       worker/ (кэш, не включён)
```

Истина лежит в таблице Google: её можно открыть и читать глазами, а при нужде
править руками. Приложение и сайт — способы в неё смотреть и писать.

Своего сервера нет. Ни одна часть не зависит от GitHub: он здесь хранилище
кода, а не звено работы.

## Проверки

```sh
node apps-script/test-local.js     # бэкенд целиком, без Google-аккаунта
```

Браузерные наборы (Playwright) живут вне репозитория — это инструмент
разработки, а не часть системы.

## Демо-режим

В `app/js/config.js` поставить `MOCK_MODE: true` — приложение заработает на
встроенных данных без всякого бэкенда. Учётки: `ivan` / `1234` (сотрудник),
`maria` / `0000` (администратор).

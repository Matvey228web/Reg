# app — склад

То, чем пользуется сотрудник склада. Открывается из Telegram как
мини-приложение и точно так же в обычном браузере по адресу
[mifs-rent.pages.dev](https://mifs-rent.pages.dev).

HTML, CSS и JS без сборки: файлы лежат как есть и как есть выкладываются.
Фреймворков нет намеренно — на складе телефоны разные, и лишние сотни
килобайт там стоят секунд.

## Что умеет

Каталог с поиском и фильтрами · карточка вещи с историей выдач и дефектов ·
выдача и приём по QR · дефекты и доска ремонта · заказы студентов ·
инвентаризация сканированием · этикетки · сотрудники и роли · настройки.

## Из чего состоит

Всё — один `index.html` с экранами-вкладками; переключает их `router.js`.

| Файл | За что отвечает |
|---|---|
| `config.js` | адрес бэкенда, `MOCK_MODE`, запасной справочник категорий |
| `api.js` | единственная точка обращения к бэкенду и к демо-данным |
| `mock-data.js` | имитация бэкенда; грузится **только** при `MOCK_MODE` |
| `telegram.js` | обёртка над Telegram WebApp SDK, тема, safe area |
| `auth.js` · `pin.js` | вход по логину и PIN, сессия, смена PIN |
| `cache.js` | кэш списков в браузере и строка «обновлено N минут назад» |
| `catalog.js` · `item.js` | каталог и карточка вещи |
| `scan.js` | сканирование, выдача, приём, дефект |
| `orders.js` · `order.js` | заказы студентов и карточка заказа |
| `repair.js` · `inventory.js` | дефекты и сверка склада |
| `myrent.js` · `announcements.js` | «My rent» (объявления студентов, модерация админом) и объявления склада |
| `app.js` | запуск: экран «Главная», связка экранов и роутера |
| `labels.js` · `qr.js` | этикетки, генерация QR, сохранение картинкой |
| `models.js` · `staff.js` · `settings.js` | справочники и администрирование |
| `util.js` · `suggest.js` · `fab.js` · `pull.js` | помощники и мелкая механика |

## Что стоит знать, прежде чем править

**Бэкенд отвечает 5–8 секунд.** Это потолок Apps Script, а не наш код. Отсюда
кэш в `cache.js`, отсюда же правило: сверка и поиск считаются на телефоне по уже
загруженным данным, а не запросами.

**`?v=` у своих файлов — не украшение.** WebView Telegram держит страницу жадно;
версия в адресе заставляет перечитать файл. Работает это только вместе с
`_headers`, который запрещает кэшировать саму страницу.

**Вне Telegram всё должно работать.** `telegram.js` мягко деградирует: нет
SDK — нет нативных кнопок, но экраны живут. Это не вежливость, а страховка на
случай блокировки мессенджера.

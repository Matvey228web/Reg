# Бот в Telegram: настройка по шагам

Интерфейс BotFather английский, поэтому ниже везде указано, что именно нажимать.
Всё, что здесь делается, делаете **вы** — токен бота я не прошу и не должен
видеть (почему — в конце).

---

## Шаг 0. Что вообще даёт бот

Три разные вещи, и путать их не стоит:

1. **Бот — это вход в приложение.** Мини-приложение Telegram открывается только
   из бота. Сейчас вы, скорее всего, открываете адрес в браузере: приложение
   работает, но Telegram не сообщает ему, кто вы, а на телефоне блокирует
   скачивание файлов. Через бота — не блокирует.
2. **Бот пишет в чат склада** о дефектах и по кнопке — сводку просрочек.
3. **Приём заказов с сайта через бота не работает** — и это ограничение
   Telegram, а не наша недоделка. Подробности в конце.

---

## Шаг 1. Найти бота и открыть его настройки

1. Откройте в Telegram чат с **@BotFather**.
2. Отправьте `/mybots`.
3. В списке выберите своего бота. Если бота ещё нет — отправьте `/newbot`,
   BotFather спросит имя (`Name`) и адрес (`Username`, обязан заканчиваться на
   `bot`), и в ответ пришлёт строку вида `123456789:AAF...` — это и есть **токен**.
4. Появится меню с кнопками: `API Token`, `Edit Bot`, `Bot Settings`,
   `Payments`, `Delete Bot`.

Если токен вы когда-то теряли — `API Token` покажет его снова, а
`Revoke current token` там же выдаст новый и сломает старый.

---

## Шаг 2. Сделать так, чтобы бот открывал приложение

Это главный шаг: после него склад открывается кнопкой в боте, а не ссылкой.

1. В меню бота нажмите **`Bot Settings`**.
2. Нажмите **`Menu Button`**.
3. Нажмите **`Configure menu button`**.
4. BotFather попросит **URL** — отправьте:

   ```
   https://mifs-rent.pages.dev
   ```

5. Дальше он попросит **название кнопки** — отправьте, например:

   ```
   Склад
   ```

Готово. Откройте бота: слева от поля ввода появится кнопка «Склад», и по ней
открывается приложение прямо в Telegram.

> Если вместо `Menu Button` вы видите `Menu Button` неактивным — значит выбран
> не тот бот: вернитесь `/mybots` и выберите нужного.

---

## Шаг 3. Положить токен туда, где ему место

Токен нужен приложению, чтобы бот мог писать в чат. Кладём его **на сервер**, а
не в настройки приложения:

1. Откройте таблицу склада → **Расширения** → **Apps Script**.
2. Слева нажмите шестерёнку — **Project Settings**.
3. Промотайте до **Script Properties** → **Add script property**.
4. **Property**: `TELEGRAM_BOT_TOKEN`
   **Value**: сам токен, строка вида `123456789:AAF...`
5. **Save script properties**.

Ни один эндпоинт этот токен наружу не отдаёт — я это специально проверил в коде.

---

## Шаг 4. Узнать id чата склада

Бот должен знать, куда писать. Чат опознаётся числом, а не названием.

1. Создайте группу для склада (или возьмите существующую).
2. **Добавьте в неё своего бота** — без этого он писать не сможет.
3. Напишите в группе любое сообщение, например `/start@имя_вашего_бота`.
4. Откройте в браузере адрес, подставив свой токен:

   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```

5. В ответе найдите `"chat":{"id":-1001234567890`. Это число вместе с минусом и
   есть id чата. **У групп он отрицательный** — минус обязателен.

Если ответ пустой (`"result":[]`), значит сообщений после добавления бота не
было: напишите в группу ещё раз и обновите страницу.

---

## Шаг 5. Вписать чат в приложение и проверить

1. В приложении: **Настройки** → поле **«Чат склада для уведомлений бота»** →
   вставьте число из шага 4 → **Сохранить**.
2. Там же, в разделе **«Бот в Telegram»**, нажмите **«Проверить связь с чатом»**.

В чате должно появиться сообщение «Проверка связи». Если нет — приложение
покажет причину прямо на экране: нет токена, не указан чат или Telegram отказал
(чаще всего бота забыли добавить в группу).

---

## Шаг 6. Ежедневная сводка просрочек (по желанию)

Кнопка **«Отправить сводку по просрочкам»** работает сразу. Чтобы она уходила
сама каждый день:

1. Apps Script → слева часы (**Triggers**) → **Add Trigger**.
2. **Choose which function to run**: `dailyOverdueDigest`
3. **Select event source**: `Time-driven`
4. **Select type of time based trigger**: `Day timer`
5. **Select time of day**: например `9am to 10am`
6. **Save**.

## Чего бот не умеет, и почему

**Читать сообщения другого бота.** Заказы с сайта присылает бот Tilda, и логично
было бы, чтобы наш бот их подхватывал. [Telegram этого не
позволяет](https://core.telegram.org/bots/faq): бот не получает сообщения других
ботов даже будучи админом группы с выключенным privacy mode. Есть режим
[bot-to-bot](https://core.telegram.org/api/bots/bot-to-bot), но он описан со
стороны MTProto, и будет ли он работать через обычный Bot API — надо проверять,
а не предполагать.

Рабочие пути к той же цели:
- **вебхук самой Tilda** — сайт шлёт заказ напрямую нам (см. `IDEAS.md`, там же
  оговорка про пять секунд на ответ);
- **переслать сообщение руками** — заказ вставляется в «Заказы» копипастом, это
  уже работает.

## Почему я не прошу прислать токен

Токен бота — это полный доступ к нему: писать от его имени, читать всё, что ему
доступно, сменить кнопку меню на чужой адрес. Присланный в переписку, он
попадает в историю и считается скомпрометированным с этой секунды — и лечится
только заменой через `Revoke current token`.

Ровно это уже произошло с токеном Cloudflare, который присылали раньше; его
по-прежнему стоит заменить.

Мне для работы токен не нужен: код, который его использует, читает значение из
Script Properties и написан вслепую — это нормально и правильно.

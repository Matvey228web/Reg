# Mifs Rent — как этим пользоваться

Склад оборудования Киноколледжа #40. Кто что может, как делаются обычные дела,
что лежит в таблице.

Настройка с нуля — в `SETUP.md`, бот — в `BOT.md`, выкладка — в `DEPLOY.md`.

---

## 1. Из чего всё состоит

**Приложение** — `mifs-rent.pages.dev`, открывается из Telegram и из браузера.
Само ничего не хранит.

**Таблица Google** — это и есть склад. Её можно открыть и почитать глазами.

**Бот в Telegram** — почтальон: пишет в чат склада о дефектах, по кнопке шлёт
сводку просрочек, приносит этикетки архивом. Без бота система работает, просто
молча.

Стоит это ноль рублей в месяц.

## 2. Три вида учётных записей

| | Главный администратор | Администратор | Сотрудник склада |
|---|---|---|---|
| Выдавать и принимать | да | да | да |
| Заводить оборудование | да | да | да |
| Дефекты: заводить и закрывать | да | да | да |
| Заказы: вести | да | да | да |
| Инвентаризация | да | да | да |
| Этикетки | да | да | да |
| Категории: заводить и править | да | да | **нет** |
| Модели: переносить между категориями | да | да | **нет** |
| Исправлять заводской и инвентарный номер | да | да | **нет** |
| Сроки и защита входа | да | да | **нет** |
| Обслуживание (выгрузка, подрезка) | да | да | **нет** |
| Кнопки бота в настройках | да | да | **нет** |
| Включать и выключать сотрудников | да | да | **нет** |
| Сбросить PIN сотруднику | да | да | **нет** |
| **Заводить и удалять сотрудников** | **да** | нет | нет |
| **Менять роль сотруднику** | **да** | нет | нет |
| **Передать главенство** | **да** | нет | нет |
| Сменить свой PIN, выйти | да | да | да |

Главный администратор один. Первый заведённый администратор им и становится.
Удалить его нельзя — только **передать** главенство, и тогда прежний остаётся
обычным администратором. Его PIN не сбрасывает никто, даже другой
администратор.

**Самозаписаться нельзя.** Учётные записи заводит только главный администратор.
Исключение одно — самый первый вход на пустой таблице, после него дверь
закрывается навсегда.

## 3. Экраны

Внизу пять вкладок.

**Главная** — кто вы и четыре плитки: «Инвентаризация», «Этикетки», «Сайт
MifsRent», «Сотрудники» (последняя только у администраторов).

**Каталог** — весь склад. Поиск по названию и номеру, фильтры по категории и
статусу, «+ Добавить» заводит позицию. Нажатие на строку открывает карточку
вещи: где она, что с ней было, какие дефекты.

**Скан** — камера открывается сразу. Отсканировали QR — получили карточку и три
действия: «Выдать», «Принять», «Дефект». Номер можно ввести руками.

**Ремонт** — все дефекты: кто завёл, когда, насколько серьёзно, чем кончилось.
Нажатие открывает карточку вещи.

**Заказы** — заказы студентов. Проще всего вставить сообщение бота целиком:
номер, состав и данные разберутся сами. Можно завести и вручную.

Ещё три экрана без вкладки: **Инвентаризация** и **Этикетки** с главной,
**Настройки** — шестерёнка справа вверху.

Каталог, ремонт и заказы можно **потянуть вниз, чтобы обновить** — в свежих
версиях Telegram. В старых этот жест закрывает мини-приложение, поэтому там его
нет: обновляйтесь кнопкой «Обновить».

## 4. Обычные дела

### Выдать
Скан → QR → «Выдать» → выбрать заказ (или «Без заказа») → «Подтвердить выдачу».
Дата возврата подставится из заказа.

### Принять
Скан → QR → «Принять». Если что-то не так — переключатель «Обнаружен дефект?»
и описание с серьёзностью. Серьёзный дефект снимает вещь с выдачи.

### Завести оборудование
Каталог → «+ Добавить» → категория → модель (или «+ Новая модель») → серийный
и инвентарный номера. Номер вещи система выдаёт сама.

Он шестизначный и читается по парам: **XX YY ZZ** — категория, модель,
экземпляр. `010101` — первая камера первой модели.

### Исправить номер у вещи
Карточка вещи → внизу «Исправить номера» (только у администратора) → поправить →
«Сохранить номера». Пустое поле стирает номер.

Номер вещи (XXYYZZ) при этом **не меняется**, значит и этикетка остаётся верной.
Занятый номер система не примет и скажет, у какой вещи он уже стоит: два
одинаковых номера означают потерянную единицу.

У полок с учётом количеством формы нет — личных номеров у них не бывает.

### Разобрать категории
Настройки → «Модели по категориям». Список сгруппирован по категориям, у каждой
модели видно число позиций. Смените категорию в строке — модель переедет со
всеми позициями.

При этом **у вещей меняются номера**: номер начинается с номера категории.
Система заранее скажет, сколько позиций тронет, и покажет, какие номера какими
стали. Ссылки в журналах переписываются, история вещи не теряется.

Отсюда следствие: **разберите категории до того, как печатать этикетки.**

Одинаковые модели в целевой категории сольются в одну. Перенести модель в
категорию с другим способом учёта (поштучно ↔ количеством) система не даст.

### Инвентаризация
Главная → «Инвентаризация» → выбрать область (весь склад или категория), при
желании указать, сколько позиций проверить наугад → «Начать сверку». Дальше
сканируйте подряд, окно сканера закрывать не нужно.

Во время обхода приложение не делает запросов — всё считается по загруженному
каталогу. Запрос будет один, в конце, по кнопке «Завершить».

Выборочная сверка ловит системное расхождение не хуже полного обхода: двадцать
случайных позиций — десять минут вместо вечера.

Сверка переживает закрытие приложения: отметки лежат в телефоне, вернётесь —
продолжите. «Сбросить отметки» обнуляет отмеченное, «Отменить сверку» закрывает
её целиком.

### Этикетки
Каталог → «Этикетки» (или с главной). Размеры показаны в ряд в настоящую
величину; нажатие на образец открывает этикетку крупно.

Как получить файлы:
- **одна этикетка** — открыть крупно → «Сохранить картинку»;
- **пачка** — «Сохранить картинками»;
- **печать** — только из Safari, не из Telegram.

| Откуда | Что произойдёт |
|---|---|
| Обычный браузер | Файл скачается как обычно |
| Telegram, есть лист «Поделиться» | Откроется лист, там «Сохранить в Фото» |
| Telegram, листа нет | Картинку пришлёт бот в чат склада |
| Пачка в Telegram | Бот пришлёт архив в чат склада |

Внутри Telegram скачать файл напрямую нельзя, и удержать картинку тоже — это
ограничение мессенджера.

Те же кнопки есть на карточке любой вещи и сразу после того, как завели новую
позицию. Сохраняется этикетка целиком, а не голый QR.

## 5. Что внутри: таблица

Читать можно свободно, писать — осторожно.

| Вкладка | Что лежит |
|---|---|
| **Equipment** | Сам склад: номер, название, категория, модель, серийный и инвентарный номера, статус, заметки, количество |
| **Models** | Справочник моделей: какой модели какой двузначный номер в категории |
| **Categories** | Категории: код из трёх букв, номер, название, считается ли количеством |
| **Staff** | Сотрудники: имя, логин, **отпечаток** PIN, роль, активность, токен сессии |
| **Students** | Студенты-арендаторы: имя, телефон, ник в Telegram |
| **Orders** | Заказы: номер, студент, представитель, даты, проект, статус |
| **OrderItems** | Состав заказов: строка заказа, модель, сколько заказано и выдано |
| **Transactions** | Журнал выдач и приёмов: кто выдал, кому, когда, когда вернули |
| **Defects** | Дефекты: что, кто заметил, насколько серьёзно, чем кончилось |
| **Inventory** | Журнал сверок: что искали, что нашли, кто и когда сверял |
| **ImportMap** | Какая колонка чужой таблицы чем является при импорте |
| **ImportRules** | По каким словам в названии раскладывать технику по категориям |
| **Meta** | Служебное: счётчики, настройки, отметки |
| **Clients** | Осталось от прежней схемы, не используется |

### Что можно править руками

- **Названия** и **заметки** — свободно. Название категории удобнее менять в
  приложении: Настройки → Категории (приложение берёт подписи из листа
  `Categories`, а не из кода).
- **Заводской и инвентарный номер** — лучше из приложения, карточка вещи →
  «Исправить номера»: в ячейке никто не проверит, не занят ли номер.
- **ImportMap** и **ImportRules** — для этого они и сделаны.

### Чего руками лучше не трогать

- **Номера в `Equipment` и `Categories`** — они напечатаны на этикетках.
- **`status` в `Equipment`** — его ведут выдача и приём, правка рассогласует его
  с журналом.
- **`pin_hash` и `session_token` в `Staff`** — первое отпечаток, а не PIN
  (вписать новый нельзя, сбрасывается из приложения), второе ключ от сессии.
- **Строки в `Transactions`, `Defects`, `Inventory`** — это журналы, удалённая
  строка означает «этого не было».

### Про ведущий ноль

Номера — **текст**, а не числа: `010101`, а не `10101`. Нужные колонки заранее
помечены текстовыми. Если вставляете руками и ноль пропал — вставляйте через
«Специальная вставка → Только значения».

## 6. Чего система не умеет

**Быстро.** Обращение к таблице стоит 5–8 секунд — цена бесплатного бэкенда.
Поэтому каталог кэшируется, а сверка не делает запросов во время обхода.

**Принимать заказы с сайта сама.** Заказ вставляют сообщением бота или заводят
руками.

**Печатать из Telegram.** Для печати откройте приложение в Safari.

**Работать без сети.** Каталог покажется из кэша, но выдать или принять нельзя.

## 7. Если что-то пошло не так

**«Нет связи» или долгое ожидание.** Если приложение молчит дольше двух минут,
оно скажет, что таблица не ответила, и предупредит: данные **могли и
записаться**. Прежде чем повторять, посмотрите каталог.

**Приложение показывает старое.** Telegram держит страницу в кэше. Закройте и
откройте заново; не помогло — Telegram → Настройки → Данные и память →
Очистить кэш.

**Вход заблокирован.** После нескольких неверных PIN вход блокируется на время
(сколько попыток и минут — в настройках). Снимет администратор или время.

**Забыт PIN.** Сбрасывает любой администратор на экране «Сотрудники». PIN
главного администратора — только он сам.

**Сотрудник уволился.** Не удаляйте — выключите: удаление убирает его имя из
истории выдач.

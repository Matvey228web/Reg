Команда запускает уборщика: сначала отчёт, ничего не удаляет без подтверждения пользователя. Если аргумента нет, проверяется весь репозиторий.

Задача пользователя: $ARGUMENTS

Запусти агента `clean` через инструмент Agent (subagent_type: `clean`). Промпт агенту составь по-английски и самодостаточным: он не видит этого разговора. Отчёт агента перескажи пользователю по-русски, коротко.
